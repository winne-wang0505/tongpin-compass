# 3分钟演示脚本

准备：使用独立 Demo 数据库和两个随机密码账号；或注册两个虚构成人测试账号。不要使用真实个人资料演示。屏幕先明确显示“虚构成人 / 模拟AI”。

0:00–0:25 首页：说明这是邀请制双向比较，不是人物评分、配对网站或关系成功预测。打开示例，指认未知项。

0:25–0:55 账号A：打开我的资料与择偶偏好，展示自己的年龄28与期待25–35是两种信息；把关系目标设为必须满足。修改后等待已保存。

0:55–1:20 创建邀请，展示7天有效期、链接不带个人信息、初次生成后复制。在独立浏览器账号B接受。接受不等于授权。

1:20–1:50 双方分别勾选年龄、关系目标、吸烟习惯；分享预览显示自己的资料和偏好。先只同意一方，展示不能生成；再同意另一方。

1:50–2:20 生成报告：账号B年龄40时，A→B与B→A不同；展示已知覆盖率、未知、边界冲突。刷新后结果不变。模拟AI必须保留标签；真实环境未配置则显示未启用。

2:20–2:40 修改A资料后，旧报告标为历史版本。说明新匹配需新邀请与授权，不能偷偷改变旧快照。

2:40–3:00 撤回授权，在另一账号刷新后报告拒绝访问。设置中展示本人数据导出和账号删除入口，说明无法收回对方截图。
