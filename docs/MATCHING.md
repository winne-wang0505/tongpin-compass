# 匹配规则 v1

只计算本次双方授权快照中双方都勾选的维度。每个勾选同时授权自己的该项资料和偏好，预览显示精确内容；未分享偏好不参与计算，也不贡献覆盖率分母，防止反向泄露。

年龄是数值区间（18–120）；城市、关系目标、吸烟、家庭计划、财务安排为枚举（城市为精确文本）；沟通频率为 1–5 有序量表区间；兴趣为多选交集（至少一个）；家庭计划遇到任一方“可协商”呈讨论项，不强判不满足。

重要性：必须满足=3、偏好=2、可以协商=1、尚不确定=不参与。可另选轻/普通/重点系数1/2/3。明确边界只适用于必须满足，已知冲突独立列出，不能由聚合抵消。

方向 A→B = A 的偏好比较 B 的情况；B→A 独立计算。未知和待协商不进入满足率分子分母；未知允许/不允许只影响讨论说明，不变成不匹配。覆盖率=已有明确比较结果的有效权重/已授权且已设定偏好的权重。未授权项不显示名称或私人状态。

至少3个已知维度且覆盖率≥60%才显示偏好满足率。分数=已满足权重/已知权重；两方向不合并。这个百分比不是人的价值、科学兼容性或关系成功率。

相同输入和规则版本结果相同；报告保存资料、偏好、授权版本及快照。更新资料只将旧报告标为历史；生成新报告需新邀请和双方重新授权。授权撤回或邀请撤销永久阻断该报告。删除报告删除整个共享报告并关闭该邀请，避免重复生成。
