# 同频 Compass 开发记录

目标：两名成年声明用户在独立账号内填写、邀请、分别授权，生成可追溯双向报告；第三人无法访问，撤回立即阻断。

架构：React + TypeScript，Express 单实例，SQLite 外键事务，Better Auth 邮箱密码。Node 24.19.0 已存在。选择独立部署以满足产品自有账号要求，不依赖 Sites 平台身份。无队列、向量库、多 Agent。

顺序：确定性引擎与权限验证 → 完整页面及两账号流程 → 隐私/失败恢复 → 手机 QA → 构建/文档/部署准备。

外部上线阻塞：真实 SMTP、模型服务配置、运营主体/联系邮箱/部署地区、主机和公开发布授权。没有配置不得假装完成。

## 本轮结果

- 真实账号与权限闭环已实现；11项本地程序测试通过，2项Edge端到端测试通过。
- 已检查桌面首页与手机报告截图；320px基础页面无横向溢出。
- 迭代1：密码标签包含辅助文本影响精确定位 → 增加可访问名称 → 注册流程通过。
- 迭代2：测试未等待登录跳转即导航导致会话尚未写入 → 等待实际登录完成 → 刷新和重新登录报告验证通过。
- 迭代3：报告解释过于笼统 → 显示已授权的期待和对方填写值，AI适配继续剔除原始值 → 引擎/API测试通过。
- 迭代4：数据库恢复可能恢复已删除用户或已撤回授权 → 增加独立删除日志及恢复时关闭所有旧授权的步骤；恢复脚本尚未实测。
- 格式化源码并固定依赖锁文件；干净目录依赖安装通过。
