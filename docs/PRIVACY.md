# 隐私说明草案

此文档与 /privacy 页面对应。上线前必须补全真实运营主体、联系邮箱、部署地区及 AI 服务方。未填项是上线阻塞，不使用虚构联系人。

- 仅服务主动声明已满18岁的成年人；声明不代表身份核验。
- 收集账号邮箱、框架生成的认证凭证/会话、主动填写的资料和偏好版本、邀请摘要、授权快照、报告及最小操作日志。不要求姓名、照片、地址、单位或精确收入。
- 默认私密。邀请链接不允许查看资料。每个分享维度同时授权本人资料与偏好，页面展示精确预览；报告直接展示各自授权的资料和偏好，只使用双方共同授权维度进行匹配。另一方不能代为同意。
- 仅双方同意时，AI适配层传送经过最小化的确定性结果；不传邮箱、令牌、实际城市文本或未授权内容。生产启用模型前，服务方隐私政策须可查看。
- 撤回后接口立即拒绝报告访问；已打开页面约10秒复核或恢复前台时复核；网络不可用时清除报告显示。不能收回截图或对方已经保存的副本。
- 导出只含本人资料/偏好历史和本人授权。删除报告关闭本轮邀请；删除账号级联删除资料、偏好、账号会话、邀请及双方关联报告，保留另一人的独立资料。
- 认证所需Cookie不用于广告跟踪；生产日志不记录敏感正文。
- 当前无自动云备份。上线须落实加密备份和最长30天轮换。删除日志独立保存到所有相关备份过期并完成恢复核验；恢复数据库时重放删除，并关闭全部旧共享授权，防止已撤回状态被恢复。
- SQLite删除覆盖不是底层存储安全擦除承诺。不宣称已满足所有地区法律要求或通过认证。
