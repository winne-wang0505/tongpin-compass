# 使用条款草案

仅供成年人自愿填写并邀请另一位成年人使用。不得冒充他人，不得代替他人授权，不得将产品用于骚扰、羞辱、歧视、操纵或非法调查。

结果只是对本次填写偏好的比较，不评价人格或人的价值，不保证自述资料真实，也不表示恋爱成功率、婚姻成功率或科学兼容性。用户应结合真实交流自主判断。

AI内容可能有误，仅作为讨论辅助；服务失败时规则结果仍可访问。用户可跳过问题、修改资料、撤回授权、删除账号。已经保存到应用外的副本无法自动回收。

第一版不提供公开人物库、附近用户、聊天、支付、身份证认证或社交平台抓取。

运营主体、联系方式、部署地区和具体争议处理方式尚待上线前确认。本草案不构成已完成法律审阅的声明。
